# Solana NFT Minter

React dApp для мінтингу NFT на Solana з Anchor та Metaplex. Базовий UI для взаємодії з смарт-контрактом.

## Фічі
- Кнопка для мінтингу NFT.
- Інтеграція з wallet (Phantom).
- Devnet-ready.

## Setup
1. `npm install`
2. `npm start`
3. Підключи wallet, мінт!
